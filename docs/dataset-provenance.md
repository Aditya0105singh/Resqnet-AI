# Data provenance

Everything the application ships with is **synthetic or generated by this repository**, except the real map data of two Kerala areas (OpenStreetMap roads and bridges, Copernicus terrain) and the 2018 river-discharge and rainfall timing (below). No real SOS messages or real incidents are included.

| Data | Location | Origin | Licence / terms |
|---|---|---|---|
| Riverbend city graph | `backend/app/simulation/world.py` | Generated procedurally (fixed seed 2026) | Part of this repository |
| Incidents, reports and false alarms | Generated per run from the scenario seed | Synthetic | Part of this repository |
| Riverbend gazetteer (landmarks and multilingual aliases) | `data/geographic/riverbend_gazetteer.json` | Hand-written fictional places, marked `"synthetic": true` | Part of this repository |
| SOS evaluation set (54 messages: English, Hindi, Malayalam) | `data/evaluation/sos_cases.jsonl` | Written for this project. Not real messages and not translations of real messages | Part of this repository |
| Benchmark results | `data/evaluation/benchmarks/` | Generated by `scripts/run_benchmarks.py` from the simulator | Reproducible from the code and seeds |
| OSM test fixture "Testvale" | `backend/tests/fixtures/testvale.osm` | Hand-made **fictional** town in OSM XML format, placed near 0°N 0°E (in the ocean) so it cannot be mistaken for a real place. Used only by tests | Part of this repository |

## Real-world data: Kerala

The app's real maps are the Kerala snapshots below; the OSM extract is the source of the place names SOS uses.

### 1. Kerala map snapshots (Aluva · Periyar River, Chengannur · Pamba River)

Built by `scripts/build_map.py` and committed as JSON in `backend/app/data/maps/`, so runs are deterministic and work offline.

| Layer | Source | Terms |
|---|---|---|
| Roads, bridges, rivers, shelter candidates | OpenStreetMap, via the Overpass API | ODbL 1.0, © OpenStreetMap contributors |
| Terrain | Copernicus DEM GLO-30 (30 m surface model) via Microsoft Planetary Computer | Copernicus open licence |
| People (incident weighting) | Building density; Aluva also carries WorldPop 2018 population | per product |
| River discharge, 14–18 Aug 2018 (Kerala 2018 scenario) | GloFAS v4 reanalysis via Open-Meteo, stored in `backend/app/data/events/` | per product |
| Rainfall shaping SOS arrivals | IMD 0.25° gauge-based daily totals, hourly shape from ERA5 | per product |
| Validation of the modelled flood footprint | Sentinel-1 RTC (9 and 21 Aug 2018), see [flood_validation.md](flood_validation.md) | per product |

What is real and what is not on these maps:

- **Real:** road and bridge geometry (simplified to a junction graph), the river line, terrain, the 2018 river-discharge curve and rainfall timing.
- **Assumed or generated:** bridge deck clearances (derived from terrain), shelter capacities (six relief camps per map at indicative sizes), units, incidents, SOS messages and **inundation depths**, which come from the simulator's threshold model. The scenario replays the flood's timing and intensity, not observed flood extent.
- **Weak on Aluva:** against Sentinel-1 the modelled footprint has skill on Chengannur (AUC about 0.76) but little on Aluva (AUC 0.51 to 0.61). The validation document says so, with the reasons.
- **Project-added:** the named places for SOS (`backend/app/data/landmarks/kerala_aluva.json`, built by `scripts/build_landmarks.py` from the OSM extract below) attach each place to the nearest junction of the coarse graph (within 0.6 km; many places share a junction). Hindi and Malayalam names for 9 well-known places, in `data/geographic/sources/aluva.aliases.json`, are marked `added_aliases` and are not OpenStreetMap data.

### 2. Central-Aluva OSM extract (source of the SOS place names)

| Data | Location | Origin | Licence / terms |
|---|---|---|---|
| Aluva OSM extract (central Aluva and the Periyar, about 2.7 km × 1.6 km; bounds 10.1025–10.1173 N, 76.3488–76.3732 E) | `data/geographic/sources/aluva.osm` | Exported from openstreetmap.org | ODbL 1.0, © OpenStreetMap contributors |
| Named places attached to the Kerala snapshot's junctions | `backend/app/data/landmarks/kerala_aluva.json` | Built by `scripts/build_landmarks.py` from the extract and the aliases file | ODbL 1.0 derived data |

The generic converter `scripts/build_geo.py` (OSM extract to a city file under `data/geographic/`, selectable through the `geography` override) is kept for adding other areas and is covered by tests on a fictional fixture; no real-city file is shipped from it, because the Kerala snapshots above are the maps the app uses.

**No result on any map describes the 2018 Kerala floods as observed.** The Kerala 2018 scenario replays the river discharge and rainfall timing only.
